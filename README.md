# Stochastic sampling in a Physics-Informed Neural Network: the deuteron ground state

Bachelor thesis project in Physics, Università degli Studi di Milano, A.Y. 2025/2026.

A Physics-Informed Neural Network (PINN) that solves the radial Schrödinger equation for the
ground state of the deuteron using Monte Carlo sampling instead of a fixed spatial grid.

## What this is

In a PINN the wave function is represented by a neural network, which is trained without any
data: the residual of the Schrödinger equation is put into the cost function and minimised.
PINN models applied to nuclei so far evaluate that residual on a fixed uniform grid, and a
grid does not scale, because the number of points needed grows exponentially with the
dimensionality of the problem.

Here the grid is replaced by stochastic sampling:

- collocation points are generated by a Metropolis algorithm targeting `P(r) ∝ |u(r)|²`, so
  they concentrate where the probability density is larger;
- a small set of fixed anchor points keeps the physics imposed also where `|u|²` is small
  (asymptotic tail, origin);
- two separate sets of points are used: only Metropolis points for the energy, Metropolis
  points plus anchors for the residual and the constraints;
- the energy is not an input. It is estimated as the mean local energy over the sampled
  points, `E ≈ (1/M) Σ E_loc`, and fed back into the residual, smoothed by a moving average.

The method is then applied to the realistic deuteron: the coupled ³S₁-³D₁ channels with the
Argonne v18 potential, with a network with two outputs (`u_S`, `u_D`) and shared hidden layers.

## Results

- binding energy reproduced with a relative error of order 10⁻²;
- quadrupole moment Q_d = 0.2413 fm², against the AV18 reference value of about 0.270 fm²;
- the D wave grows from the origin as ~r³. This is never imposed: it emerges from the
  minimisation of the residual, where the centrifugal barrier penalises faster growth;
- convergence reached with a quarter of the collocation points of the grid-based model and
  about four times faster, on a harder, coupled-channel problem.

## Running it

Python with PyTorch, all computations in double precision. Developed and run on Google Colab with
an NVIDIA T4 GPU. Plots and the best model are written to `images/` and `model/`.
